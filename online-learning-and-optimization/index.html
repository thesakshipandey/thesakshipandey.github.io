Online Learning and Optimization

EE6106 course notes covering Expert Advice, Multi-Armed Bandits, and MDPs.

Online Learning and Optimization

This course studies sequential decision-making under uncertainty. The central question throughout is: can a learning agent compete with the best fixed strategy in hindsight, and if so, how quickly?

The answer depends heavily on what the agent observes and what the adversary knows. The three parts of the course each probe a different regime.

Part 1: Prediction via Expert Advice

The agent observes the outputs of $K$ experts at each time step and must predict a sequence generated by an adversary. The key challenge is combining expert advice optimally without knowing which expert is best.

Topics:

  • Majority Algorithm
  • Weighted Majority Algorithm
  • Exponential WMA
  • Randomized Exponential WMA

Key result: Sub-linear regret $O(\sqrt{n \ln K})$ is achievable with soft, convex loss or a randomized algorithm.

Part 2: Multi-Armed Bandits (MABs)

The agent pulls one arm at a time and observes only its reward. The other arms remain hidden. This partial feedback forces exploration, unlike the full-information expert setting.

Topics:

  • EXP3: Adversarial Bandits
  • Stochastic MABs: Setup and Full-Info Setting
  • Explore-then-Commit (ETC)
  • Upper Confidence Bound (UCB)
  • Anytime UCB
  • Epsilon-Greedy
  • Information-Theoretic Lower Bounds
  • Pure Exploration: Fixed Budget
  • Pure Exploration: Fixed Confidence

Key results: Logarithmic regret $O(\ln n)$ is achievable and optimal (up to constants) for stochastic MABs. Adversarial bandits pay an extra $\sqrt{K}$ factor over the full-information case.

Part 3: Markov Decision Processes (MDPs)

The agent interacts with an environment that has state. Actions affect future states, so the agent must plan, not just react. When the model is unknown, this becomes reinforcement learning.

Topics:

  • MDP Basics and Value Functions
  • Bellman Equations
  • Bellman Operators and Value Iteration
  • Linear Programming Approach and Q-Functions
  • Policy Iteration
  • Expected Time-Average MDPs
  • Reinforcement Learning

Key results: Discounted infinite-horizon MDPs always have an optimal stationary, deterministic, Markovian policy. Value Iteration and Policy Iteration both converge. The ETA (undiscounted) case is more subtle and requires additional structural conditions.

Course Arc

The course progressively relaxes assumptions:

Setting Feedback Adversary Regret
Expert Advice Full (all experts) Oblivious $O(\sqrt{n \ln K})$
Adversarial MAB Partial (chosen arm) Oblivious $O(\sqrt{nK \ln K})$
Stochastic MAB Partial (chosen arm) Stochastic $O(\ln n)$
MDP Full state Stochastic Planning problem
RL Full state Stochastic, unknown Exploration required
